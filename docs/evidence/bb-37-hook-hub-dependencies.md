# BB-37 — hook-hub executable repair and verification

This branch changes hub child PATH and read-only dependency diagnostics. It does **not** install or restart the daemon, modify a live symlink, publish a notification, or certify the 24-hour observation gate.

## Notification diagnosis and deploy prerequisite

On this host `~/.local/bin/claude-notify` is a dangling link to `/home/delorenj/code/utils/claude-notifications/bin/claude-notify.js`; the target repo is absent. `~/.config/claude-notifications/settings.json` exists with `sound`, `desktopNotification`, and `webhook` keys. The supported upstream is `git@github.com:delorenj/claude-notifications.git`, package `@delorenj/claude-notifications` version 2.2.1 (verified `npm view`); its `bin/claude-notify.js` uses `#!/usr/bin/env node` and plays configured sound, optionally desktop notice. **It does not implement the configured webhook**: its `main()` only calls `playSound()` and conditional `showNotification()`. The existing ntfy setup guide's webhook assertion is therefore not proof of phone delivery. Do not claim ntfy delivery without an upstream fix and a separate test.

After independent reviews and explicit deployment authorization, install the supported package in the intended host environment (`npm install -g @delorenj/claude-notifications`), confirm `command -v claude-notify` points to a working executable and `node` resolves from the service PATH, and **do not run** `claude-notifications install` because it writes independent native hooks and would duplicate hub ownership. An existing dangling link may have to be removed/repointed by the deployment owner before npm can expose the package command; preserve its target for rollback. `claude-notify -c` prints settings, including potentially sensitive webhook URLs: do not paste its output into evidence. Test one explicitly authorized sound/desktop notification; phone delivery requires separate evidence and upstream functionality. Both `claude-notify` and `codex-turn-notify` hub rows intentionally route through the single `concerns.py claude-notify` branch; no second hook is installed. The OpenCode row shares this branch.
