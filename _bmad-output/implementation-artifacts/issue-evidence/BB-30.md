## Boundaries and remaining concerns

Capture means the successful native finalizer transaction is committed. A later
platform delivery cancellation/failure cannot rewrite that completed execution;
redelivery publishes its stored outcome. Native failed/interrupted/incomplete
execution never stores an answer. Candidate observation before durable capture
is not a restart guarantee: process loss can repeat Hermes and external effects.
No global exactly-once claim. Broker deduplication has a finite window; durable
consumers deduplicate by event ID. Runtime installation retains the Bloodbank
checkout (canonical validator/schema resources) and jsonschema.
